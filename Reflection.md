# Reflection

At the beginning of the assignment, one of the first challenges for me was to keep all the bugs organized and traceble for future developers to have this good habbit from the very beginning. Especially when the complexity of the project grows, it's getting harder to keep track on where is what, especially when you are a complete beginner. This means that all the files, names, and structure - have to be properly named and stored - mostly because it was my first time doing such an assignment, I wanted to establish this core knowledge. 

But that was rather organizational part, and after finding a few bugs,the most difficult part was when I actually needed to look into the code to understand the bugs and to prepare for the testing of these.
The biggest challenge I encountered was figuring out how to unit test a CLI app. In class, we tested simple functions like `divide(10, 2)` where you call a function, then simply check the result, then voila - done. But BankCLI Pro is interactive app where every function asks the user to type something using terminal. When I first tried to import the functions into a test file, the whole banking menu started up instead of my tests running. I had to spend quite some time to learn about `require.main === module` to prevent that, and I used `jest.mock('readline')` to simulate user input so each test could "type" answers automatically. This is certainly very interestinf insight to have, but I spent quite much time by trying to udnerstand it and it shifted my progress for quite a lot, so I had to accelerate my work to be able to meet the deadline. Also making tests themselves also took some time and pracrice because it basically covers everything we learned so far helping us to solidify the knowledge by practicing and brainstorming the solutions.

It was a very challenging, but interesting project to be working on. With my background in UI/UX, I already knew the importance of testing, but this course helped me to finally see the world of testing from inside, from the coding point of view - how it has to be performed, what are rules - all of that opens the door of more comprehensive and automate tests that will save a lof of time and money for all kinds of projects, commercial and personal.
